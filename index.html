怎么完成一次商品图任务

有 API 和没有 API 都能使用。

  1. 导入商品素材在素材库选择清晰的 JPG、PNG 或 WebP 商品图。
  2. 建立独立任务每个任务分别设置图片类型、输出尺寸、提示词和数量。
  3. 选择 AI 来源使用官方/中转 API 或已通过连通性测试的 Codex 直接生图。
  4. 一键生成一次提交所有任务，结果会按各自目标尺寸保存并进入生成记录。
